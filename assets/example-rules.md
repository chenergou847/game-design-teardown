# 经营示例规则 v0.3

此资料为技能作者编写的虚构规格，供方法示例使用，不是现实产品、实测记录或玩家数据。

| 项目 | 规则 |
|---|---|
| 时间与行动 | 每个游戏日12行动点，不结转；玩家主动结束当天才换日，无现实等待 |
| 捕鱼 | 一次花4行动点得2鱼；每鱼可卖3金币 |
| 种植 | 每田投入3粮，连续三个浇水日后收5粮；每日每田浇水花2行动点；漏浇暂停、已浇次数保留 |
| 购粮 | 每粮4金币；粮不可出售，金币不占背包 |
| 收获与库存 | 收获不花行动点，无额外消耗；背包24单位，每物品占1单位；生产先扣消耗再入产出，溢出时当场选择丢弃 |

没有给出玩家偏好、完成率、留存或经济分布。例中新增田增产8粮为拟案设定，不属于原规则。
