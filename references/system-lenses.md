# 系统视角

按主问题选相关行，八类无需逐项写满。数据列是可收集的线索，具体数值仍需资料支持。

| 系统 | 主要拆解对象 | 数据与过程线索 | 常见联动 |
|---|---|---|---|
| 核心玩法与战斗 | 输入、动作、敌我状态、交互条件、资源、协同、命中与失败恢复 | 动作/冷却时序、启动条件、消耗、有效距离或窗口；一次遭遇中的可行动作与状态变化 | 成长提供能力；关卡检验能力；教学解释失败 |
| 成长与养成 | 获得、解锁、升级、装备、构筑、专精与重配 | 成长前后参数及可用动作、投入与回报、获得门槛；同局面下的变化 | 经济供给、内容难度、多人公平与能力获取 |
| 关卡与探索 | 空间、路线、视线、地标、遭遇、解谜、节奏与奖励 | 可达路径、能力门槛、遭遇顺序、风险与回溯成本；首次和重复路线 | 任务导航、资源奖励、能力解锁 |
| 经济与资源 | 来源、转化、存储、消耗、交易、过期与退出渠道 | 净产出、单位效率、周转资金、容量、到账顺序；固定预算下的完整路线 | 探索准备、成长投入、付费获得与公平 |
| 任务与叙事 | 目标、步骤、调查、提交、分支、结算与后续世界状态 | 访问/追问成本、分支条件、可知信息、补救窗口；选择后的实际状态差异 | 关卡线索、时间资源、多人进度和重玩 |
| 社交与多人 | 分工、沟通、匹配、竞争、决策权、共同目标与奖励分配 | 个人/队伍可见信息、贡献和计票口径；掉线、迟到、超时及重连时的状态处理 | 任务提交、能力差距、协作激励 |
| 教学、界面与反馈 | 目标发现、信息层级、操作入口、错误恢复、教学顺序与辅助设置 | 信息何时对谁可见、操作步骤、反馈时点；知道入口、理解用途、执行与自主迁移的记录 | 服务主系统中的具体选择 |
| 长线内容与商业化 | 日常、活动、赛季、回归、内容供给、付费能力与外观 | 周期、获取条件、成本、奖励与补偿；完整周期和错过后的恢复路径 | 资源消耗、成长难度、多人公平、回归教学 |

全游戏拆解先给“主玩法→支撑资源与成长→内容循环”的结构图，再选关键链条深入。范围之外的系统同样按入口、状态、条件、动作、成本和结果拆解。产品没有的结构保留为空，不补写。
