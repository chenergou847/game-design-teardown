# game-design-teardown

用于作品集和策划决策的游戏设计拆解技能。覆盖八类系统，支持单游戏、跨系统与跨游戏对照。

输出以规则、数值、流程和紧凑图表为主；设计判断集中在正文末尾，最后附资料来源表。原型按需展开相关边界与验证。

成稿前确认数据可得性；多场景任务采用规则骨架、完整总览与代表案例。修正字段保留原值和采用依据，关键案例连到失败恢复及整体资源后果；交付区分数据、来源、呈现和导出检查。

```text
$game-design-teardown 拆解某游戏的经济系统，用于作品集，并判断怎样借鉴到我的经营原型。版本与资料是……
```

## 资源

- SKILL.md：流程与完成标准。
- references/system-lenses.md：八类系统的拆解对象与数据线索。
- references/analysis-method.md：口径、图表、分析与引用。
- references/data-workflow.md：资料取舍、字段追溯与分层验收。
- assets/report-template.md：可裁剪报告骨架。
- references/worked-example.md、assets/example-rules.md：虚构示例及可定位的规则资料。

默认中文Markdown，其他格式按需衔接对应工具；没有实测数据时以规则和标注的推演支撑。技能不依赖固定API、私有数据库或脚本。

安装时保留整个目录，放入Codex个人技能目录（通常为用户目录下.codex/skills；自定义CODEX_HOME时使用其skills目录）。会话未刷新时在新对话显式调用。版本、评测记录与分发包保存在开发工作区，结构检查不代表行为效果提升。
